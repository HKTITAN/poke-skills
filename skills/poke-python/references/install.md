# Install

```bash
pip install poke
```

- **Python**: 3.8+ for the core SDK.
- **Python 3.10+** required for the MCP callbacks module ([[mcp-callbacks]]) — it uses async features added in 3.10.
- **Zero runtime dependencies** — pure stdlib.

The package on PyPI is also named `poke`: https://pypi.org/project/poke/.
