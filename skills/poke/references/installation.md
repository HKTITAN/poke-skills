# Installation

```bash
npm install poke
```

- Node.js **>= 18** required.
- Ships both CJS (`dist/index.cjs`) and ESM (`dist/index.mjs`).
- TypeScript types bundled (`dist/index.d.ts`).
- Same package provides the global CLI — install with `-g` if you want the binary on `PATH`. See [[../../poke-mcp-tunnel/SKILL]].
