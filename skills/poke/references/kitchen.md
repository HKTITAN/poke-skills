# Kitchen — the developer dashboard

**[poke.com/kitchen](https://poke.com/kitchen)** is where developers manage everything Poke-side.

## What lives there

- **API keys** — create / rotate V2 keys at [poke.com/kitchen/api-keys](https://poke.com/kitchen/api-keys). Keys are shown **once** at creation; copy and store immediately. See [[api-keys]].
- **Recipes** — create / edit / publish shareable Recipes. See [[../../poke-recipes/SKILL]].
- **Payouts** — track referral revenue from published recipes. See [[../../poke-recipes/references/publishing-payouts]].

## When to send the user there

- "I need a key" → [poke.com/kitchen/api-keys](https://poke.com/kitchen/api-keys).
- "I want to ship a recipe" → [poke.com/kitchen](https://poke.com/kitchen) → "Create recipe".
- "How do I see what I've earned" → Payouts tab in Kitchen.

## What's NOT in Kitchen

- **Connected integrations** — that's at [poke.com/integrations](https://poke.com/integrations). See [[../../poke-integrations/references/integrations-ui]].
- **The agent itself / chat** — happens in iMessage/Telegram/SMS, not the web. See [[overview]].
