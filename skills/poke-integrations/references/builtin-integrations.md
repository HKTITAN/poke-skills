# Built-in integrations

Poke ships prebuilt recipes for these services — Poke handles the OAuth / API-key dance.

## Productivity / dev

- **Linear** — issue tracking, projects, cycles.
- **Todoist** — tasks.
- **Notion** — pages, databases.
- **Asana** — tasks, projects.
- **GitHub** — repos, issues, PRs.
- **DeepWiki** — codebase Q&A.
- **Sentry** — error/performance monitoring.
- **Vercel** — deployments, projects.
- **Netlify** — deployments, sites.
- **Supabase** — db, auth, storage.

## Business / ops

- **Ramp** — corporate cards, expenses.
- **Webflow** — sites, CMS.

## Communication / personal (built into the agent)

- **Gmail** + **Microsoft Outlook** — multi-account email, multi-calendar, contacts (Dec 2025).

## Browse / connect

- Catalog: [poke.com/recipes](https://poke.com/recipes).
- Tag filters: Calendar, Community, Developer, Email, Finance, Health, Home, Productivity, Scheduling, Shopping, Students, To-dos, Travel.

## What if it's not on this list?

Two options:
- The service has its own MCP server → use [[custom-mcp]].
- You're building one → see [[../../poke-mcp-tunnel/references/tunnel-local]] for local dev, [[../../poke-mcp-tunnel/references/mcp-add-remote]] for deployed.
