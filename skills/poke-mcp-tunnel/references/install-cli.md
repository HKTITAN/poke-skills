# Install the CLI

```bash
npm install -g poke
```

- Node.js **>= 18**.
- Provides the `poke` binary on `PATH`.
- Same package as the SDK ([[../../poke/references/installation]]) — the `-g` flag is what exposes the CLI.

After install, log in: [[login]].
